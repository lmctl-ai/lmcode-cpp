# Boundary and hostile-wire coverage

Core corpus: 406 vectors, generated by mono `lmscript/scripts/generate-dsl-conformance.ts`.
The 324 additions retain lmcode bytecode (DSLB v6), the existing host stub:
301 executable partitions and 23 loader/verifier rejection cases. The merged
corpus also keeps nine concurrent return-lowering cases with exact sink/frame
expectations; these are additional to this job's 324 cases.

The arithmetic matrix uses host-bound operands and a separate signed-i64 BigInt
oracle; it partitions signs, int32/2^53 boundaries and wrapping, all comparisons,
boolean truth tables, finite float arithmetic/order, range break/continue,
empty/reversed ranges, switch no-fallthrough, UTF-8/string escapes and inlined
parameter/local isolation. Hostile vectors mutate decoded operands/container
fields for invalid bool/index/arity, MATH IDs, jump targets, local-slot bounds, line
maps and range/while topology. They must fail load before execution. load_error expectations pin the exact error
code on line 2 and the message substring on line 3 (manifest: {code, message}).
The 23 hostile cases cover 21 predicate families, with import-index and
instruction-boundary checks reached from multiple regions.

Regenerate in mono, then run `make test conformance` here. The native runner
requires manifest/file-set agreement for `.expect`, `.dslb` and `.dsl` files, unique
vector names and existing schemas; `make conformance` runs deletion/addition
controls before executing both corpora. SDK ports sync committed
bytes using scripts/sync-vectors.sh and their digest locks. A stale or modified
copy must fail its pin verifier. Numeric trace tolerances use the existing ~ rule.

Coverage is not exhaustive: import reachability is distinct from domain/value
semantics; opcode coverage does not imply every verifier branch. Filesystem and
registry API errors need native/CLI controls. Sample wrappers test outer-language
splices and compiler errors; they are not VM opcodes. Return-sink/block-value work
is a separate addition and is not asserted by this boundary corpus.
